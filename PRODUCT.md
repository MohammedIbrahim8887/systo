# Systo
<!-- impeccable:product-schema 1 -->

## Platform
web

## Users and purpose
A macOS desktop system monitor for the user’s MacBook, replacing Activity Monitor with an approachable process manager inspired by Windows Task Manager.

## Stack and operating context
Existing Farm.js, React and Electrobun application; local macOS process data. Desktop-only installer.

## Capabilities
Grouped processes, performance charts, process explanations, end-task actions, and a notch/Dynamic Island overlay.

## Brand commitments
The user selected the monochrome Core logo and the Island Preview installer concept. Approved references: assets/design/core-reference.png and assets/design/installer-reference.png. Preserve the existing monochrome application interface.

## Open decisions
Public distribution, signing identity, and notarization are not configured by this request.
