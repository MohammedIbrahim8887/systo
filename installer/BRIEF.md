# Installer direction
Mode: Operate. Implement the user-selected Island Preview composition: white window, Core logo and Systo wordmark, oversized headline, Mac display/notch illustration, monochrome island metrics, supporting copy and one installation action. Reference: ../assets/design/installer-reference.png.

Use a local, offline WKWebView in a native macOS app with native title-bar controls. The illustration is a preview with explicitly illustrative data. Install the bundled app to Applications, safely stage copies before moving them into place, handle existing installs and errors, then offer Open Systo. Never show fake percentage progress. Retain native keyboard and close behavior.
